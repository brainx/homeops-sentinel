## Editorial decisions

“Zero-risk guarantee” → “Explicit review. Visible validation. Defined recovery.”

“AI agent swarm secures the home” → “AI assists explanation and proposals; rule and runtime evidence establish conclusions.”

“Live 99.8% mesh stability” → “Mesh health unknown” until metrics have a source, scope, sampling window, and definition.

“No explicit max means unbounded” → “Parallel mode defaults to 10; an explicit cap is a policy choice.” Verified against [Home Assistant automation modes](https://www.home-assistant.io/docs/automation/modes/).
